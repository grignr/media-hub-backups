Privacy policy

Last updated: 21 October 2026.

Media Hub Backups is a personal backup integration operated by GitHub user grignr. It is intended only for the operator's own Google account.

Google Drive access and use

The integration uses rclone with Google Drive authorization to create, list, upload, download, verify, and manage retention of backup files in a designated backup location. Access is used solely for personal backup and recovery. The selected OAuth permission scope determines the access Google grants; a designated folder is an operating convention and does not itself restrict that scope.

Backup contents and encryption

Backups can contain server configuration, authentication credentials, and assistant conversation or memory data. The intended production workflow encrypts backup contents locally using rclone crypt before upload. Recovery passwords and keys must be kept separately. Google receives encrypted backup objects and associated storage metadata.

Storage and sharing

Local backup copies and rclone authorization credentials are stored on systems controlled by the operator. Cloud copies are stored in the operator's Google Drive. The integration does not sell Google user data, share it with advertisers, or use it to train AI models. Decrypted backup data is used only for recovery and verification. Google and GitHub process data under their respective service policies.

Retention and control

Backup retention is controlled by the operator's backup configuration; no fixed automated retention period is promised until that configuration is enabled. The operator can delete cloud backups using Google Drive or rclone and revoke authorization through Google Account third-party connections. Revoking authorization does not delete existing backups. Local copies must be managed separately.

This website

These static pages contain no application analytics, advertising scripts, forms, or embedded trackers. GitHub Pages may collect technical request information as part of hosting the site.

Contact

Contact the operator through repository issues. Never publish credentials, recovery keys, or private backup data there.

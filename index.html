Media Hub Backups

Media Hub Backups is a private backup integration operated by the GitHub user grignr for personal use. It uses rclone to copy encrypted server backup files to the operator's Google Drive account and retrieve them for recovery checks.

This integration is not offered as a public service. Authorization is intended only for the operator's own Google account. It does not provide public access to backup files.

Privacy policy

Contact: repository issues. Do not post credentials, personal backup contents, or recovery keys in public issues.
